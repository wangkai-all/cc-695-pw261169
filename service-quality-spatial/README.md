# 片区服务质量空间分析

本地单页应用：在 8×8 虚构城市网格上，用虚构服务记录判断**高延迟是否集中在相邻区域**。

## 打开方式

无需构建、无外部依赖，直接用浏览器打开：

```
service-quality-spatial/index.html
```

## 功能

- **片区统计量**：每个片区计算样本量 n、平均延迟、有效覆盖（14 天观察窗内有记录的天数占比）。
- **两种邻接规则**：共享边（Rook）/ 共享角（Queen），切换后地图、邻居表、权重、全部统计量同步重算。
- **整体空间关联**：全局 Moran's I，行标准化权重，给出随机期望 E[I]。
- **局部空间关联**：LISA（局部 Moran），分类为 高高聚集 / 低低聚集 / 高低离群 / 低高离群 / 不显著。
- **可重复的随机置换**：随机种子可调，同种子结果完全一致；页面显示置换次数决定的最小可分辨 p = 1/(N+1)。
- **同类型片区内置换**：可切换为只在商业 / 住宅 / 工业同类片区之间置换，避免把类型基线差异当作空间相关。
- **多重比较校正**：局部检验经 Benjamini–Hochberg FDR 校正，只有校正后 q ≤ 0.05 的片区才在地图上着色。
- **单列不当作零值**：无服务记录、覆盖不足（n < 30 或覆盖 < 50%）、无有效邻居的片区全部剔除并单列，名单随邻接规则变化。
- **点击格子**：查看实际邻居、行标准化权重、参与计算的服务记录、z 分数、空间滞后、Iᵢ、原始 p、BH q 与分类。
- **成对样本**：两组片区取值完全相同（同一多重集、同均值同方差），仅空间排列不同，Moran's I 截然相反 —— 结论不能仅由平均值决定。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构 |
| `styles.css` | 设计令牌（浅 / 深色）与布局 |
| `app.js` | 数据生成、统计核心（Moran / LISA / 置换 / BH）、渲染 |

数据为内置虚构数据（生成种子固定）；页面上的"随机种子"只控制置换检验的随机序列。
